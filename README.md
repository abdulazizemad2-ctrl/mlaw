# محاكي اختبار الميد: مبادئ القانون

اختبار إلكتروني تفاعلي لمادة مبادئ القانون، مقصور على مواضيع الملخص الأربعة:

1. مفهوم النظام وتمييزه عن غيره
2. أقسام النظام
3. مصادر النظام
4. درجات النظام وإجراءات إصداره

يضم 265 سؤالاً من التجميعات واختبار الميد السابق، مع أسئلة جديدة. فيه وضع اختبار ووضع تدريب، وتحليل للنتيجة حسب الجزء، ومراجعة للأخطاء مع الشرح.

## التشغيل

افتح `index.html` في المتصفح، أو فعّل GitHub Pages للمستودع من الإعدادات (Settings ← Pages ← Branch: main).

إعداد: ملخصات أبو عماد
